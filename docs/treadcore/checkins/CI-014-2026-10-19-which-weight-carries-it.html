Abstract

CI-013 found +2.31 ± 0.58 a seat with three landfall weights on together: landfall_memory 30, landfall_shy 1, landfall_wait 10. This step took each back to 0 in turn over 48 seeds. Without the memory, -1.08 ± 0.53. Without the stand-off, +0.69 ± 0.64. Without the run's price, +1.50 ± 0.67. The memory is the base: the other two cost a point without it and add about 2.4 a seat between them with it. All three together is the best setting measured. The defaults are Paul's.

Index terms: ablation, complementary features, memory, weights.

III. Methods

From CI-013's weights file (memory 30, shy 1, wait 10), three files each with one of the three set to 0. Each run: CENSUS_WEIGHTS, 48 seeds as three ranges of 16 side by side, naval.map, 900 s, respawns 3, the fair census, CENSUS_ACTS. The runs went one after another. Each reads against the null (the defaults for every team) seed by seed.

V. Discussion

  1. Complementary parts. The memory knows where a gun is; the run's price keeps the boat's course off it; the stand-off keeps the boat off a beach it covers. Each needs the memory, and each adds to it.
  2. Differences between trials are rough. Each run is paired with the null, not with the others, so "the stand-off adds 1.6" carries the errors of two runs (about 0.9).
  3. The values are hand-picked. 30 s, 1 and 10 s were the first tried. The tuner (backlog 23) can search them once they are on.
