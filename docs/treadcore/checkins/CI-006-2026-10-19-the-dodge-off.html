Abstract

The shell dodge was the code held last at 43% of deaths (CI-004), and holding it longer cost 1.18 a seat (CI-005). This step turned it off for the trial team over 48 seeds: -2.45 ± 0.67 a seat, outside the noise. The dodge pays. A rough counterfactual from the meter shows it nearly halving the dodged shell's hits ashore and changing nothing afloat. Backlog 28 closes. Backlog 31, a weight for dodging afloat, is the next part.

Index terms: reflexes, ablation, counterfactual, paired census.

III. Methods

CENSUS_CAPS=-dodge (the trial team's dodges false; Commander:: set_settings), the defaults for the baseline teams. CENSUS_SEED0 0, 16, 32 with CENSUS_SEEDS=16, side by side; naval.map, 900 s, respawns 3, the fair census, the ledger off.

The part: Commander::think_on calls self.dodge.order_with(..) (lib.rs), which starts the watch and meters, and then filters the order by self.dodges; holding is likewise gated by dodges. With the switch off, the meter therefore records each dodge the trial team would have made and its outcome undodged.

Estimate: with the trial team's share of shells taken as one third, run rate r = r_u / 3 + 2 r_d / 3, so r_u = 3r − 2r_d, with r_d the null run's dodged rate (CI-004).

V. Discussion

  1. A death census overstates a reflex. The code most deaths passed through is the part worth most. Before reading any reflex's share of deaths, the ablation has to be run.
  2. Ashore and afloat are two parts. The same dodge saves a tank and costs a boat its crossing for nothing. That is an either/or, so it becomes a weight.
  3. Instrument by team. The meter's per-world counts forced an estimate; per-team and taken-or-not counts make the next reading exact.
