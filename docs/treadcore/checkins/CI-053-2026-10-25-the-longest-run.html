Abstract

The first night of backlog 69: about ten hours on the census machine, queued at 18:40. Block 1 reads eight profiles against the new defaults. Block 2 screens sixteen weights at half and double. Block 3 runs SPSA over the five weights the screen ranks first, chosen by a script written before the screen, then reads its point on 400 held-out seeds. Each block's rule and our expectations were written before it played, so the morning can score the predictions as well as the brain. Nothing changes a default overnight.
