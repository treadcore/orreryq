Abstract

Two items from CI-020's conversation. First, the census scripts now run a frozen copy of the test binary, so brain code can change while a census plays. This was proved by breaking the source mid-run, and the run finished with an identical reading. Second, on Paul's choice, the capability smooth is now a weight, w_smooth, with an insignificant default of 0.05. Its numeric parts blend by the weight; its yes-or-no parts act above 0.5. The old play against the new default reads +0.47 ± 0.60 a seat over 48 seeds.

Index terms: tooling, reproducibility, weights, either-or rule.
