Machines, Machines

Pick a machine on the left. Probe reads it and changes nothing. A new machine goes in the box at the foot as NAME user@address, and Join puts it in the fleet. Every recipe that changes a machine asks first and shows what it will run.

  1. The selected machine, lit. Green words mean it is new and not yet in the fleet.
  2. Everything the probe read: system, CPU, GPU, disk, tools, power-off.
  3. Pull projects, Join and Probe act on this machine.
  4. Each recipe's state: not for it, applied, not applied (amber), ready to run.
  5. Apply or Run. Each asks first, then types its command into a Sessions tile for you.
  6. Add a machine.
  7. What was done here, and when.
What it doesAdds a computer to the fleet: probe it, apply a recipe, join it.
Where it ties inThe very start of the line. No machine, no lane, no reads.
Why it is drawn this wayA list with one step lit, because a setup is a sequence and the next step is what matters.
What to look forA machine stuck on a step, or a recipe that says ready to run.
What is simulatedNothing runs here. It only makes a machine able to run the census and build the brain.
Why it helps the brainMore lanes means more seeds an hour, and that is the only currency the search spends.
