Steps

  1. Orrery → Projects → Finish, then out; wait for “Removed”.
  2. Reboot, DEL. Make the other changes first (CSM off, AC BACK, logo off, PXE off).
  3. F11 → Save Profile “stock” (the way back).
  4. X.M.P. → Profile1. Fill in the profile line above.
  5. DRAM Voltage = profile (1.35 V). Enhancement: Normal.
  6. F10. First boot is slow; the board may cycle a few times.
  7. Cycles 3× and comes back at defaults? F11 → Load “stock”, go to If unstable.
  8. Ubuntu: sudo dmidecode -t 17 | grep Configured
    should read 3200 MT/s, 1.35 V on all four.
  9. Stress test (calber still out of the queue), below.
  10. Tell Claude → speed bench ram-bench.sh calber 3200.
  11. F11 → Save Profile + USB stick. Then Orrery Add.

If unstable — one change at a time

  1. Command Rate 2T.
  2. VCCSA 1.15 V, VCCIO 1.10 V; then +0.05 V (limits above).
  3. Speed 3000, profile timings and voltage kept.
  4. Speed 2933.
  5. Give up safely: XMP off, 2666 at 1.2 V (multiplier 26.66): the CPU’s own rating, no test needed.

Stress test (1 hour)

sudo apt install stress-ng
stress-ng --vm 4 --vm-bytes 75% --vm-method all \
  --verify -t 1h
Any “fail” or a crash = unstable. Stricter: MemTest86 from USB overnight.
Bad memory fails silently: wrong census results or a damaged island checkpoint, not a crash. Do not skip the test at 3000+.
